Настольная утилита для очистки диска C: в Windows: **нажмите «Начать сканирование» → программа покажет, что можно удалить → у каждого пункта видны риск и последствия удаления → вы отмечаете нужное → подтверждаете и очищаете**.

Один exe, без установки и без дополнительных библиотек (только встроенный .NET Framework 4.x).

**[Скачать последнюю версию](https://github.com/ankeji/DiskMate/releases/latest)** · **[Сообщить о проблеме](https://github.com/ankeji/DiskMate/issues)**

![Стартовый экран](screenshot.png)

## Возможности

- **Сам диск не трогает.** При запуске открывается только приветственный экран; чтение начинается после «Начать сканирование» (или F5).
- **Сканирование можно отменить.** 13 шагов с прогрессом; отмена не оставляет изменений.
- **Три уровня риска.** Каждый пункт помечен как низкий / средний / высокий, указано «что удаляется» и «что будет после»; по умолчанию отмечены только безопасные.
- **Четыре карточки-метрики.** Всего, низкий, средний, высокий — клик фильтрует.
- **Панель деталей.** Влияние, рекомендация, реальные пути и «Открыть папку».
- **Полностью собственная отрисовка интерфейса.** Без системных контролов и сторонних библиотек — одинаковый вид при любом DPI.
- **10 языков интерфейса**, по умолчанию упрощённый китайский; переключение сразу и запоминается.
- **Обновление внутри программы.** Один клик слева внизу: проверить → скачать → проверить SHA-256 → заменить → перезапустить.

## Обновление внутри программы

1. Слева внизу постоянно показано `v2.1.0 · Проверить обновления`; при наличии новой версии кнопка становится синей «Обновить до v2.1.x».
2. Окно показывает сравнение версий и список изменений; «Скачать и установить» запускает загрузку с прогресс-баром.
3. Затем файл проверяется по SHA-256, и небольшой bat-скрипт заменяет exe после закрытия программы и запускает новую версию.

Проверяются два источника, побеждает более новая версия:

- `https://raw.githubusercontent.com/ankeji/DiskMate/main/version.txt`
- `https://api.github.com/repos/ankeji/DiskMate/releases/latest` (резерв, без авторизации 60 запросов/час/IP)

Релиз одной командой: `powershell -ExecutionPolicy Bypass -File scripts\release.ps1 2.1.1 "изменения" "notes"` — отправленный тег запускает сборку и публикацию Release в GitHub Actions.

## Сборка

Достаточно .NET Framework 4.x из Windows 10/11:

```bat
git clone https://github.com/ankeji/DiskMate.git
cd DiskMate
build.bat
```

`build.bat` использует системный `csc.exe`: собирает `_build.exe` без значка, создаёт `app.ico` и пересобирает `DiskMate.exe` уже со значком. Visual Studio и NuGet не нужны.

Самопроверка: `DiskMate.exe --selftest` (отрисовка страниц, наложения элементов, пропущенные переводы).
