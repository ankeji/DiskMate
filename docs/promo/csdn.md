## 二、为什么推荐它

### 1. 打开不会自己扫描

绝大多数清理软件一启动就开始扫硬盘，风扇狂转、硬盘灯闪。DiskMate 进入后是**待机状态**，必须先点「开始扫描」才会动——硬盘什么时候忙，由你决定。

### 2. 每一项都写清楚"删了会怎样"

不是简单一句「清理垃圾 XX MB」，而是三个维度：

- **风险等级**：低风险 / 中风险 / 高风险（默认只勾选低风险）
- **影响范围**：这个项目到底会动哪些文件
- **处理建议**：什么情况下可以删、什么情况下别删
- **实际路径**：告诉你文件到底在哪，可以自己去看一眼

### 3. 单文件、免安装、不联网

- 只有一个 `DiskMate.exe`，绿色版，拷走就能用
- 只有「检查更新」会访问 GitHub，其余全程本地
- 不写注册表、不装服务、不留后台进程

## 三、下载与安装

### 方法一：直接下载（推荐）

打开 Releases 页面：

```text
https://github.com/ankeji/DiskMate/releases/latest
```

下载 `DiskMate.exe`（约 822 KB），放到任意目录（例如 `D:\Tools\DiskMate\`）双击运行即可。

### 方法二：从源码编译

需要 .NET Framework 4.x 自带的编译器（Windows 自带，不用装 VS）：

```bat
git clone https://github.com/ankeji/DiskMate.git
cd DiskMate
build.bat
```

编译产物就是根目录的 `DiskMate.exe`。

> 国内访问 GitHub 慢的话，用任意加速镜像下载 Release 附件即可；源码也可以从镜像站拉。

## 四、使用教程（6 步）

### 第 1 步：以管理员身份运行

双击 `DiskMate.exe`，UAC 弹窗点「是」。清理系统缓存（`C:\Windows\Temp`、更新残留等）需要管理员权限，普通权限会跳过这些项目。

### 第 2 步：选择要扫描的磁盘

左上角默认勾选 C 盘，需要的话可以再勾 D 盘（侧边栏会实时显示各盘占用）。

### 第 3 步：点「开始扫描」

点击后才会开始扫描，过程中有进度和阶段提示，随时可以取消。

### 第 4 步：看结果，按需勾选

扫描完成后进入结果页：

- 顶部是「可清理 XX GB」的汇总
- 中间列表可以按**类别**（浏览器缓存 / 系统临时文件 / 更新残留 / 回收站 / 大文件……）和**风险等级**筛选
- 右侧详情面板显示选中项的**影响 / 建议 / 路径**
- 「全选低风险」按钮可以一键勾选安全项

### 第 5 步：确认并清理

点「加入清理」→ 查看已选统计 → 点「开始清理」→ 二次确认 → 执行。清理过程有进度，完成后会提示释放了多少空间。

### 第 6 步：需要时导出日志

每一页都有日志页面，记录扫描、勾选、删除的每一步，出问题可以据此排查。

## 五、功能与风险分级说明

| 风险 | 含义 | 典型项目 | 默认勾选 |
|---|---|---|---|
| 低 | 删了不影响系统和软件使用 | 系统临时文件、回收站、浏览器缓存、软件更新包残留 | ✅ 是 |
| 中 | 删了会丢一些便利性数据 | 下载目录里的安装包、缩略图缓存、部分应用缓存 | ❌ 否 |
| 高 | 可能影响正在使用的东西 | 正在使用的浏览器缓存、休眠文件、较大的个人文件 | ❌ 否 |

补充说明：

- **浏览器缓存**：建议先退出浏览器，否则被占用的文件会被自动跳过（日志里会写跳过数量）
- **WinSxS\Temp**：属于系统组件目录，普通管理员也删不掉，工具会跳过而不是硬删
- **大文件扫描**：不进入 `C:\Windows`，避免扫描时间过长

## 六、软件内升级怎么用

不用每次都去 GitHub 手动下新版：

1. 左下角常驻版本号 `v1.0.1 · 检查更新`；
2. 有新版本时按钮变蓝，显示「更新到 v1.0.x」；
3. 点开弹窗可以看到**当前版本 → 最新版本**和更新说明；
4. 点「下载并安装」→ 自动下载 → SHA-256 校验 → 自动替换 → 几秒后新版本自己打开。

也可以手动点按钮检查，启动 2.5 秒后会自动静默查一次（有新版本只弹一条提示，不打扰你）。

## 七、常见问题 FAQ

**Q1：为什么提示需要管理员权限？**
清理 `C:\Windows\Temp`、更新残留等目录需要管理员权限。不给权限也能用，但会跳过受限项目。

**Q2：会不会误删我的文件？**
扫描阶段只读、不写不删；删除前有二次确认；高风险项默认不勾选；详情面板能看到每个项目对应的实际路径。

**Q3：软件会收集我的数据吗？**
不会。除了「检查更新」访问 GitHub 读取版本清单，其余全部本地完成，没有任何统计上报。

**Q4：清理后浏览器要重新登录？**
清理「浏览器缓存」不会退出登录；但如果勾选了 Cookie/站点数据相关的项目，就会掉登录态——这类项目被标为中/高风险，默认不勾。

**Q5：125% / 150% 缩放（笔记本高分屏）下界面乱吗？**
已经适配。软件按系统 DPI 等比缩放整套界面（100% / 125% / 150% / 175% / 200% 都测过，字体、按钮、间距、列表列宽一起变）。如果觉得字太大或太小，可以在 `%LOCALAPPDATA%\DiskMate\settings.ini` 里加一行 `scale=1.25` 手动指定。

**Q6：支持 Windows 7 吗？**
需要 .NET Framework 4.x；Win7 SP1 装过 4.x 可以运行，但只在 Win10/11 上做过完整测试。

**Q7：杀毒软件报毒怎么办？**
软件是单个未签名 exe，且会请求管理员权限、清理系统目录，容易触发启发式误报。源码全部开源，可以自行用 `build.bat` 编译一份对比哈希。

## 八、技术实现亮点

给同样在做 Windows 桌面小工具的同学参考：

1. **全自绘 UI**：不要任何 UI 框架，圆角卡片 / 矢量图标 / hover 反馈全部用 GDI+ 画，界面不再"2008 年管理后台"风。
2. **高 DPI 真适配**：设计稿按 96 DPI 写，统一乘全局系数 `Theme.S`；字体用像素单位创建避免二次放大；控件内部绘制常量同样按比例缩放。
3. **自替换升级**：运行中的 exe 无法覆盖自身，通过生成临时 bat 等待进程退出 → `copy /y` 重试 → 启动新版 → 脚本自删；下载包先做 SHA-256 校验。
4. **零第三方依赖**：只用系统自带的 .NET Framework 4.x，JSON 解析器也是手写的（100 行），保证"单文件、零运行时"。
5. **可自动化的界面自检**：`DiskMate.exe --selftest` 会渲染界面并检查文字溢出、控件越界、控件重叠，可用 `DISKMATE_SCALE=1.5` 复跑不同缩放，避免改布局改出新问题。
