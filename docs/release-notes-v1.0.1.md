## DiskMate v1.0.1

1. 侧边栏磁盘占用条：空间不足时自动省略「可用 / 总容量」字样，只留数字，避免文字压到右侧百分比
2. 行高按字体实际高度计算，125% / 150% / 200% 缩放下文字与进度条不再重叠
3. 磁盘占用条支持中 / 繁 / 英（「可用」「总容量」「不可用」）

### English
1. Disk meters now drop the "free / total" wording when space is tight, keeping only the numbers so nothing overlaps the percentage
2. Row height derives from the real font height, so text no longer collides with the bar at 125% / 150% / 200%
3. Disk meters are localized (zh-CN / zh-TW / en)
